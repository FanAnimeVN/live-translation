# Manga text-block detectors: primary-source alternatives audit

Reviewed 2026-10-14. Public source/metadata research only; no model/code files downloaded, installs, inference, keys or private image uploads. Read the repository `AGENTS.md`; this note is the only file changed.

## Recommendation

The best next **preflight comparator** is the author's `ogkalu/comic-text-and-bubble-detector` ONNX release: it predicts text regions and bubbles separately, including text outside bubbles. That matches the missing grouping boundary more directly than another line detector. Its current small artifact has an Apache-2.0 model declaration and a maintained CPU adapter. Target CPU latency, memory, crop quality and bare-text paragraph ownership remain unmeasured. Do not change defaults or promise superiority from this research. [Owning card](https://huggingface.co/ogkalu/comic-text-and-bubble-detector), [author's adapter](https://github.com/ogkalu2/comic-translate/blob/8977b91a4f7a40c3917c5a268e9e7d78e1d818da/modules/detection/rtdetr_v2_onnx.py).

CTD is already a useful local comparator, but copying its whole grouping pipeline is not yet justified. The existing private v9 experiment reports CTD detector time around 8–9 s/page versus PP around 1.1–1.4 s; its improved containment alignment is not full detector precision/recall. Those historical figures used a different grouping version and must not be pooled with today's pipeline. This audit did not rerun or verify the private outputs. [Prior local experiment](detector-primary-review-20261014.md#subsequent-local-experiment--measured-not-an-upstream-claim).

## What CTD actually supplies

The `dmMaze/comic-text-detector` source combines YOLOv5 block detection, a UNet mask head and a DB-style line head. ONNX inference through OpenCV DNN returns raw block predictions, a text mask and line probability maps. The public wrapper decodes/NMSes blocks, decodes line polygons, applies grouping, refines a mask and returns `(mask, mask_refined, blk_list)`. Thus structured paragraphs are postprocessing output, not an ONNX output tensor or an OCR transcript. The example annotation helper writes images to disk and should not be imported into the RAM-only reader. [Architecture/CPU path](https://github.com/dmMaze/comic-text-detector/blob/440b978563c71b758e31aaa315d100faba1efa2f/basemodel.py), [inference](https://github.com/dmMaze/comic-text-detector/blob/440b978563c71b758e31aaa315d100faba1efa2f/inference.py).

`group_output` assigns lines to predicted boxes using overlap; low mask density can discard unmatched lines or empty boxes. It splits Japanese/vertical blocks using spacing, merges scattered lines geometrically and sorts blocks. Language classes are `eng`, `ja`, `unknown`; they do not identify dialogue, narration, SFX or importance. Inference: evaluate raw blocks, raw lines and final groups separately, especially bare dialogue on connected paper. A predicted text mask is not evidence that erasure is safe. [Grouping source](https://github.com/dmMaze/comic-text-detector/blob/440b978563c71b758e31aaa315d100faba1efa2f/utils/textblock.py).

The translator's CTD adapter deliberately ignores YOLO grouping and emits lines for a later merger. That merger uses geometry, graph components, spacing and direction. It is another reproducible grouping ablation, not learned balloon ownership or a demonstrated solution to this project's overmerges. [CTD adapter](https://github.com/zyddnys/manga-image-translator/blob/95227a2bb0fd306cd4f0c104d57284026f991b3a/manga_translator/detection/ctd.py), [merger](https://github.com/zyddnys/manga-image-translator/blob/main/manga_translator/textline_merge/__init__.py).

## Alternatives that change the grouping problem

| Candidate | Relevant output / resource evidence | Decision for this reader |
|---|---|---|
| Ogkalu text + bubble detector | Classes `bubble`, `text_bubble`, `text_free`; small ONNX above; author uses ORT CPU, 4 intra-op / 1 inter-op threads | First preflight candidate. Direct text-region boxes can supply paragraph crops, but bare-text grouping and quantized recall need measurement. |
| Paddle `PP-DocLayout-S` | Whole layout `text` boxes; PicoDet-S, 23 document categories; official storage table 4.834 MB | Lower-priority permissive layout comparator. Its Chinese/English document training/evaluation does not establish Japanese manga grouping. |
| Manga109 bubble segmentation | YOLO11n masks for one balloon class; SafeTensors conversion 2.86M parameters, 1600-pixel inference size | Supplementary enclosed-bubble boundary evidence. It cannot detect or group bare dialogue by itself. |
| MAGI v2 | Text blocks, panels, character associations; public `pytorch_model.bin` about 2.06 GB; usage loads custom code and CUDA | Research reference only. License restrictions and broad chapter pipeline make it an unsuitable default commercial/CPU comparator here. |

Ogkalu's card describes the original RT-DETR-v2 r50vd model trained on roughly 11k comic images; it does not separately document v4-s architecture/training or an evaluation of the current small export. Do not attribute the original 42.9M parameter count to v4-s. The adapter uses PIL RGB `resize((640,640))`, float32 `/255`, CHW and a batch dimension. Inputs are `images` and int64 `orig_target_sizes=[[width,height]]`; `outputs[:3]` are assigned in order to `labels, boxes, scores`, with singleton batches removed. It retains scores >=0.3 by default, interprets boxes as original-pixel `xyxy`, and collects class 0 bubbles and class 1/2 text together. Its base pipeline merges overlapping boxes and attaches bubbles by containment/overlap, then adds heuristic lines. Retain raw class/confidence and compare those heuristics separately. [Owning card](https://huggingface.co/ogkalu/comic-text-and-bubble-detector), [pinned ONNX adapter](https://github.com/ogkalu2/comic-translate/blob/8977b91a4f7a40c3917c5a268e9e7d78e1d818da/modules/detection/rtdetr_v2_onnx.py), [base pipeline reviewed on main](https://github.com/ogkalu2/comic-translate/blob/main/modules/detection/base.py).

The ogkalu model card and author application declare Apache-2.0. This supports a reviewed minimal adapter, retaining applicable licenses/notices when copying source; the short model card does not establish complete training-rights provenance. Importing the whole app also brings download helpers and unrelated processing, so use a pinned local-file contract for offline operation. [Model declaration](https://huggingface.co/ogkalu/comic-text-and-bubble-detector), [source license](https://github.com/ogkalu2/comic-translate/blob/8977b91a4f7a40c3917c5a268e9e7d78e1d818da/LICENSE), [download helper](https://github.com/ogkalu2/comic-translate/blob/8977b91a4f7a40c3917c5a268e9e7d78e1d818da/modules/utils/download.py).

Paddle's owning card declares Apache-2.0. Its published 18.53/6.29 ms CPU figures use a Xeon Gold 6271C and eight threads on document data; they are not this machine's manga latency. Hub revision `8ac289e66575bb9bba6e15c53719d8b15cc9b3b2` lists `inference.pdiparams` at 4,804,904 bytes, SHA-256 `491c3382d84ca04d2033afbee0c105942ed82fea392bb4a19170646adebe088a`. Paddle parameters are not an already verified ONNX artifact. [Owning card](https://huggingface.co/PaddlePaddle/PP-DocLayout-S), [official output/performance contract](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/module_usage/layout_detection.en.md), [publisher metadata](https://huggingface.co/api/models/PaddlePaddle/PP-DocLayout-S?blobs=true).

The bubble producer and converter declare Apache-2.0, but the producer's sample runtime uses Ultralytics, whose current code license is AGPL v3. Audit the actual runtime and base-weight chain independently before product reuse. Its unspecific CPU timing claim is not a target-machine measurement. Conversion revision `4c9d7cbfa9905f7003677fa1130b48b93365a16a` lists `model.safetensors` at 11,480,076 bytes, SHA-256 `a58cd1b5a12c37a3178302097ed10ae57674bf420c52304e210c7ba19aded5dd`. [Producer](https://huggingface.co/huyvux3005/manga109-segmentation-bubble), [converter](https://huggingface.co/mayocream/manga109-segmentation-bubble), [metadata](https://huggingface.co/api/models/mayocream/manga109-segmentation-bubble?blobs=true), [runtime license](https://github.com/ultralytics/ultralytics/blob/main/LICENSE).

MAGI's v2 model card permits personal/research/noncommercial/nonprofit use and requires a separate arrangement for other uses; its repository says academic research only. That discrepancy needs clarification from the owner before wider use. Its example also filters `is_essential_text`; that must not silently exclude text in this reader. No target CPU timing or peak RAM was established. [Owning card](https://huggingface.co/ragavsachdeva/magiv2), [owner repository](https://github.com/ragavsachdeva/magi), [artifact metadata](https://huggingface.co/api/models/ragavsachdeva/magiv2?blobs=true).

## Required preflight and bounded benchmark

1. Pin model revision, filename, size/hash, source contract and runtime version. Use an existing locally verified artifact or a separately authorized acquisition. Fail if absent/mismatched; inference must make no network/metadata/custom-code request. Model file size and parameter count are not peak RAM.
2. For ogkalu, verify actual ONNX input/output names, dtypes, shapes, label map, original-size ordering and coordinate range. Match the author's resize/channel/normalization contract; preserve raw scores and all three classes. Do not inherit overlap merging, first-bubble attachment or tall-page slicing unnoticed. Boxes are not glyph or balloon masks.
3. For CTD, expose raw blocks/lines/masks before grouping; record letterbox/padding, output ordering and DB/NMS thresholds. The existing comparator uses a PaddleX decoder rather than bit-for-bit CTD postprocessing, so identify that ablation explicitly. Test grouping with fixed detections separately from changing detectors.
4. Freeze the existing private pages, audited labels and unchanged manga-ocr crop settings. Report missed text, false/duplicate regions, cross-dialogue merges, split paragraphs, crop contamination and order errors, including dense, vertical, small and balloonless text. Text-outside-bubble is a location class, not an automatic SFX/irrelevance label. Gold paragraph/ownership labels are required to claim improved grouping; OCR labels alone are insufficient.
5. Measure cold start, repeated warm detector/postprocessing/OCR/total timings and peak RSS on the 16 GB CPU machine with explicit threads. Report page values and difficult cases. Repeated eight-page results are limited evidence, not population p95. Require a real crop/layout gain at acceptable measured cost before integrating or distributing any candidate.

No reviewed source establishes a production accuracy improvement or the product latency targets. This note supports a small local comparator design and a licensing/provenance audit; it does not authorize a default change, neural erasure, wider dataset acquisition or packaging.
