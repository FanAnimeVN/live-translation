# Path to a defensible 78/78 OCR result

No evaluated automatic route reaches `78/78`. It remains a target, not a
guaranteed outcome of switching models, ensembling or fine-tuning. Selecting a
more flattering prediction using the current labels is not a deployable route.

## Why the recorded candidates do not establish 78/78

- The supplied Japanese labels are not independently reviewed. Several visible
  pages contain annotation/OCR conflicts (for example, the page-2 caption and
  the `さっそく` line), so a model that reads the pixels can still be marked
  wrong by the current string.
- The three-crop-recognizer subset reaches a post-hoc oracle of about 55/78,
  leaving 23 rows where none of those alternatives equals the supplied label.
  The wider recorded-route oracle below is about 56/78. Neither is a deployable
  selector or a ceiling for a new method.
- Geometry-only rotation and projection splitting both regressed on the frozen
  crops. They cannot be promoted as cheap fixes.
- Full-page loss is still detector ownership/grouping: the crop control is
  48/78 while the production page route is 35/78.

## Required sequence

1. **Review the source.** A Japanese-capable reviewer confirms each text string,
   polygon/box, reading order, role and whether nearby text belongs to the same
   utterance. Mark uncertain rows; do not force a label to make the denominator
   look better.
2. **Freeze a real split.** Keep development pages separate from title-held-out
   pages. Add Vietnamese meaning references and clean-background/glyph-mask
   references separately; Japanese OCR labels are not either of those.
3. **Fix ownership first.** Compare a line detector and a block detector on the
   same page. Preserve raw polygons/source members and route only bounded,
   reviewable missing IDs. Do not give a learned text box erasure authority.
4. **Evaluate a genuinely different recognizer.** Compare original-pixel crop
   readings without exposing the first transcript or gold to the verifier.
   If reviewed residual errors justify adaptation, use permissioned training
   data covering vertical, small, stylized, balloonless and SFX strata. Keep
   punctuation, quotes, pauses and elongated delivery as supervised characters.
   Validate on unseen titles, not random crops from the same page. Fine-tuning
   is conditional, not a prerequisite or a guarantee of 78/78.
5. **Add calibrated alternatives.** Expose token/sequence uncertainty and use
   geometry-only hard-case signals to request one bounded secondary pass. Keep
   the primary source and alternative; never silently replace text, speaker or
   memory from an unreviewed candidate.
6. **Promote only paired winners.** Require no lost ordinary text, no overmerge,
   no protected-art change, exact restoration and the latency/RAM gates in the
   goal document. A higher exact count with worse coverage is not a win.

The practical target is reviewed-gold fidelity and high ordinary recall first.
The current 78 rows remain a development/regression set, even after review;
generalization needs a separately reported unseen-title evaluation. A perfect
score on the current unreviewed labels is not a sufficient release criterion.

## Checkpoint 2026-10-17 — decision on a literal 78/78 target

The private audit was rerun against the unchanged fingerprint
`445d4e457c8ac8c56d8c17e215d683b6abb1a908ba98932729add4f679dbab7f`:

- 10 supplied images / 81 supplied rows;
- 8 eligible pages / 78 eligible rows;
- one declared-size mismatch and one duplicate image remain excluded;
- zero eligible Vietnamese references and no clean-background/glyph-mask gold.

The current page evidence is unchanged: production PP-OCRv5 + manga-ocr is
35/78 exact, the CTD line comparator is 44/78, and the review-only geometry
hybrid is 48/78. The crop recognizer control is also 48/78, while the oracle
over recorded alternatives is only a diagnostic (about 56/78) because it
chooses after seeing the supplied label.

This means literal agreement with the supplied strings alone is not a
sufficient acceptance target yet. Some rows have source-label conflicts that
need review. Memorizing erroneous test labels or selecting runtime output after
seeing gold would not establish faithful OCR. This does not imply that every
unanimous model disagreement is a label error, or that a new source-grounded
method could not legitimately reach 78/78 on a reviewed pack.

The next quality-bearing route is now explicit:

1. an independent Japanese review of text, geometry, reading order and role;
2. separate Vietnamese meaning and clean-background/glyph-mask references;
3. CTD/PP ownership-preserving high-recall proposals, with missing/uncertain
   crops sent to the bounded cloud OCR path only after the reader's cost/privacy
   consent;
4. a distinct recognizer/verifier experiment before committing to training;
   any later adaptation manifest uses only reviewed train rows with a
   title-held-out split and no gold-based runtime routing;
5. paired reruns that require coverage, no overmerge, exact restoration and
   latency/RAM gates before any default changes.

Reviewed Japanese text/geometry is sufficient to evaluate the OCR target.
Vietnamese and clean-background references are separate requirements for
translation and cleanup acceptance; their absence must not block detector/OCR
experiments or be presented as the cause of OCR errors. This eight-page set
has already been used for tuning: reviewing it does not make it held-out.

## Checkpoint 2026-10-17 — inspect pixels before treating 78 as truth

Ten selected problem rows were inspected from the supplied source crops and
again with a 20-source-pixel context halo. Both previews stayed in RAM. This
was an assistant inspection after seeing existing predictions, **not an
independent or blind Japanese review**. Private observations are in
`artifacts/private-source-pixel-review-20261017.json`, with all decisions pending
and scoring/training use explicitly disallowed.

The inspection exposes several different evaluation questions: apparently
conflicting lexical labels, a supplied transcription omitting visible text
inside its own box, punctuation counts, a decorative rule extending beyond a
tight crop, and inconsistent ruby transcription. One uncertain pause remains
explicitly uncertain; absence of an obvious mark in a preview is not permission
to delete it. Some lexical observations reconfirm earlier assistant proposals,
not additional independent reviewers. These selected examples do not estimate
the frequency of annotation errors across all 78 rows.

No annotation, score, runtime selector or production default changed. In
particular, do not train a recognizer to omit visible characters or to output
a suspected erroneous reference just to report literal 78/78. First freeze a
consistent reviewed Japanese transcription/ownership policy; then grade both
the unchanged historical pack and reviewed pack separately. Reviewed Japanese
gold is sufficient for the OCR experiment: missing Vietnamese or clean-background
gold must not be used to postpone it. Automatic, reviewer-assisted and
unresolved results must remain separate, and these already-tuned pages remain
development data.
